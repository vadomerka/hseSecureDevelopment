# CI Templates

Эта директория содержит шаблоны для настройки CI/CD практик курса SecDev.

## Содержимое

- `ci-p12-iac-container.yml` — шаблон workflow для P12 (IaC & Container Security)
- `hadolint.yaml` — шаблон конфигурации Hadolint
- `checkov.yaml` — шаблон конфигурации Checkov
- `trivy.yaml` — шаблон конфигурации Trivy

## Использование

Эти шаблоны были использованы для настройки практик P12. Актуальные конфигурации находятся в:
- `.github/workflows/ci.yml` — интегрированные CI jobs
- `security/` — конфигурации инструментов безопасности

## Примечание

Эти файлы сохранены для справки и могут быть полезны при настройке новых практик или обновлении существующих.
